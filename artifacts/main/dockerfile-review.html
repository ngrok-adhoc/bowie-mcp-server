Bowie Dockerfile review

Keep uv sync --locked --no-dev at build time and launch Bowie directly with the interpreter installed in the image.

Startup command

CMD ["/app/.venv/bin/python", "mcp_server.py"]

The independent model reviewer recommended this one-line change. Astral documents uv run as a valid Docker command. Its FastAPI deployment example is the closer match for Bowie because it installs dependencies during the build and directly invokes a virtual environment executable. Compose already uses the same Python path for Bowie's health check. Astral Docker guide · Astral FastAPI deployment example

Container checks

The reviewer and I tested the launcher variants with networking disabled. Each successful command imported FastMCP from the image while running as UID 10001.

  • uv run --no-sync --no-cache python used the built-in environment and ran Python as a child process.
  • uv run --no-sync python exited when it tried to create /.cache/uv.
  • /app/.venv/bin/python used the same environment and ran Python as PID 1.

The current Dockerfile also passed the earlier Compose startup and graceful shutdown check. This review covers the launcher. The OAuth profile and cross-platform builds were outside its scope.
